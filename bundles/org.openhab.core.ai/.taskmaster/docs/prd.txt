# openHAB AI Bundles - Product Requirements Document

## Project Overview
Implementation of MCP (Model Context Protocol) and A2A (Agent-to-Agent) bundles for openHAB using official SDKs.

## Bundle Structure
- org.openhab.core.ai.common - Shared foundation bundle
- org.openhab.core.ai.mcp - MCP protocol implementation  
- org.openhab.core.ai.a2a - A2A protocol implementation

## Official SDKs
- MCP Java SDK: https://github.com/modelcontextprotocol/java-sdk
- A2A Java SDK: https://github.com/a2aproject/a2a-java

## Testing Strategy
- Comprehensive stub framework for network dependencies
- Live openHAB integration for core services
- Hybrid testing approach (80% stubs, 15% hybrid, 5% full live)
